**A stability and counterfactual audit of motif-level explanations in cell-conditioned multi-omics drug response prediction.**

This repository contains the reproducible pipeline, the processed dataset, the split indices and the summary results of
the study *Are cell-conditioned motif explanations faithful?* (A. H. Abdelhaliem, 2026, manuscript under review).
The manuscript itself is not distributed here.

A **motif** is a chemical substructure of the drug (a BRICS or RECAP fragment); *cell-conditioned* means that its
representation is computed jointly with the multi-omics embedding of the cell line. The pipeline re-implements a
CCMG-class backbone (molecular graph + motif nodes + multi-omics cell node in one graph), trains it on GDSC2 x DepMap
under random, unseen-drug and unseen-cell regimes next to DrEval-style baselines (naive mean effect, tuned LightGBM, late
fusion), and audits five motif-level and four gene-level explainers on a fixed probe set of 2,500 drug–cell pairs:

- **Stability** across training seeds, exposure regimes and input noise, at pair level and at drug level.
- **Counterfactual faithfulness** against input-space edits of the molecule (motif deletion, size-matched motif swap) and
  of the cell (gene knockdown).
- **Agreement with biology**: GDSC targets, DepMap CRISPR dependencies, pathway-enriched motifs, positive-control
  biomarkers and author-curated pharmacophores.
- **Controls**: multi-head and entropy-regularised attention, a backbone tuning grid, a seed ensemble and a
  planted-importance sanity check of the explainers.

Headline numbers are summarised in [RESULTS.md](RESULTS.md).

## Repository layout

| Path | Content |
|---|---|
| `work/src/` | pipeline modules (data preparation, motif chemistry, splits, model, training, explainers, analysis, figures) |
| `work/build.py` | regenerates every summary table, figure and number from the run results |
| `work/data/` | processed dataset (`dataset.npz`, `meta.json`), BRICS/RECAP motif graphs, probe set and split indices, resolved SMILES |
| `work/figs/` | figures generated by `figs_tables.py` |
| `work/results/summary/` | aggregated tables: accuracy, stability, faithfulness, cell dependence, biology, controls, tuning, sanity check |
| `work/results/runs/*/metrics.json` | accuracy and training history of every neural run (140 runs) |
| `work/results/baselines/` | naive mean-effect and tuned LightGBM results |
| `work/results/explain/*/summary.json` | per-run explanation summaries (the full score matrices, ~70 MB each, are regenerated by `explain.py`) |
| `RESULTS.md` | one-page summary of the results |

## Running the pipeline

```
cd work
python src/fetch_smiles.py      # PubChem SMILES for the GDSC2 compounds (cached in data/drug_smiles.csv)
python src/prep_data.py         # GDSC2 x DepMap -> data/dataset.npz, data/meta.json   (needs the raw files, see Data)
python src/chem.py              # BRICS / RECAP motif graphs -> data/graphs_{brics,recap}.pkl
python src/splits.py            # probe set and the three exposure regimes -> data/splits.npz
python src/train.py --model ccmg --vocab brics --split random --seed 0        # one training run (~8 min on a GTX 1060 6 GB)
python src/explain.py --run ccmg_brics_random_ss0_s0                          # explainers and counterfactuals for one run
python src/gpu_queue.py         # the complete job list (training, explanation, controls, tuning grid); resumable, one GPU job at a time
python src/cpu_jobs.py          # naive and LightGBM baselines
python src/bio_controls.py      # positive-control biomarkers and curated pharmacophores
python src/sanity_gnnexp.py     # planted-importance sanity check
python build.py                 # analyze.py -> figs_tables.py (tables, figures, numbers)
```

`gpu_queue.py` and `cpu_jobs.py` were run as self-restarting Windows scheduled tasks (`gpu_launch.cmd`, `cpu_launch.cmd`);
on another machine run them directly. Every stage skips work whose result file already exists, so the queue can be
interrupted and resumed.

## Data

The processed files in `work/data/` are included (241 drugs with organic SMILES, 704 cell lines with expression,
mutation and copy number, 148,670 drug–cell pairs, 1,141-gene panel, probe set and split indices). The raw inputs are
public and are not redistributed:

- GDSC2 fitted dose–response data, release 8.5 (27 October 2023), and `screened_compounds_rel_8.5.csv`: https://www.cancerrxgene.org
- DepMap 24Q2 Public: `Model.csv`, `OmicsExpressionProteinCodingGenesTPMLogp1.csv`, `OmicsSomaticMutationsMatrixDamaging.csv`,
  `OmicsSomaticMutationsMatrixHotspot.csv`, `OmicsCNGene.csv`, `CRISPRGeneEffect.csv`: https://depmap.org
  (place them in `work/data/raw/depmap/`)
- Drug structures: PubChem PUG-REST, resolved by `fetch_smiles.py`.

## Requirements

Python 3.11, PyTorch 2.x with CUDA, PyTorch Geometric 2.x, RDKit, LightGBM, scikit-learn, SciPy, pandas, matplotlib,
psutil (`requirements.txt`). All runs were executed on a single NVIDIA GeForce GTX 1060 (6 GB).
